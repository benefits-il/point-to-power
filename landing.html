PointToPower

שני סוכנים. אחד מבנה תוכן, השני בונה דק. מצגת אחת, בעבודה נכונה.

איך מתקינים איך זה עובד
מה זה

תוכן תחילה. עיצוב אחר כך.

רוב הכלים מערבבים תוכן ועיצוב באותה שיחה ומאבדים את שניהם. PointToPower מפריד אותם לשני סוכנים שיודעים אחד על השני, ועוברים ביניהם handoff מובנה.

סוכן תוכן

Point

שואל את השאלות הנכונות. בונה מתווה שקופיות לפי שיטות מוכחות. לא נוגע בעיצוב.

  • אליציטציה רחבה לפני כל שקופית, קהל, ז'אנר, אורך, target, שפה
  • מסר אחד לשקופית. כשנדחקים שניים, מציע לפצל
  • טיפוגרפיה, צפיפות, פתקי דובר, מבנה סיפורי לפי R1
  • ממליץ על פיצ'רי NotebookLM להשראה, לא לתוצר סופי
  • פולט handoff Markdown לפי חוזה Handoff v1.0
סוכן בנייה

POWER

קורא את ה-handoff, בוחר סגנון מקטלוג, בונה את הדק. לא עורך תוכן.

  • Parse + validate את ה-handoff נגד החוזה
  • זיהוי target אוטומטי: HTML או PowerPoint
  • בחירת סגנון מתוך 35+ אופציות לפי Decision Tree של R3
  • פירוט layout פר-שקף ופרומפטי visuals מתואמי סגנון
  • פרומפט סופי ל-Claude-in-PowerPoint או ל-Claude.ai
  • iteration loop: visual / layout / style / target, בלי לאבד state
!

הפרדת תחומים מוחלטת. אם תבקש מ-POWER לשנות מסר של שקופית, הוא יחזיר אותך ל-Point. אם תבקש מ-Point להציע פלטה, הוא יחזיר אותך ל-POWER. זה לא באג, זאת הסיבה שזה עובד.

איך זה עובד

ארבעה צעדים, סוכן עובר לסוכן

אתה לא צריך לזכור פורמטים או לחזור על עצמך. ה-handoff בין הסוכנים שומר את כל ה-state.

אליציטציה

Point שואל שאלות עד שכל ה-Meta מלא ויש לפחות יחידת תוכן אחת. ברירות מחדל סבירות במקום שאלות פתוחות.

Point

handoff

Point פולט קובץ Markdown מובנה: Meta, Slides, Tail. או נשמר ב-handoff-runtime, או נדבק ב-POWER ידנית.

Handoff v1.0

סגנון + layout

POWER מאמת מול החוזה, מציע סגנון (primary / alternative / wildcard), כותב layout פר-שקף וגם פרומפטים לוויזואלים.

POWER

פרומפט סופי

POWER פולט בלוק להעתקה, ל-Claude-in-PowerPoint או ל-Claude.ai. הדק נבנה אצלך, עם state שמור ל-iteration.

Claude / PowerPoint
גבולות גזרה

איזה סוכן עושה מה

Point

תוכן

מסרים, מבנה סיפורי, מי הקהל, מה האורך, אילו שקופיות, מה speaker notes. כל שאלה על עיצוב, חוזרת ל-POWER.

POWER

עיצוב ובנייה

סגנון, פלטה, פונטים, layout, visuals, target. כל בקשה לשינוי תוכן, חוזרת ל-Point עם snapshot של ה-state.

לא בתחום

לא ייצוא PDF

POWER מפיק פרומפט לכלי החיצוני (Claude-in-PowerPoint או Claude.ai). הוא לא מייצא PDF, לא שולח מייל, ולא מעלה לדרייב.

לא תרגול

לא חזרות והעברה

אחרי שהדק נבנה, התרגול וההעברה הם עליך. הסוכנים לא מאמנים נואם, לא בודקים תזמון, ולא מספקים feedback על הקלטה.

התקנה

שלוש דרכים להתקין

אותם שני סוכנים, שלוש אריזות. בחר את הסביבה שבה אתה עובד.

פלאגין

Claude Code

להתקנה כפלאגין בתוך Claude Code. סוכנים, סקילים ופקודות נטענים אוטומטית.

  1. העתק את התיקייה claude-code/ ל-Claude Code plugins folder
  2. הפעל מחדש את Claude Code
  3. הפעל את /point לפתיחת סשן תוכן
  4. אחרי handoff: /power לבנייה
repos/plugins/point-to-power/claude-code/
פלאגין

Cowork

אותו פורמט, להתקנה ב-Cowork. דרך marketplace או local plugin manifest.

  1. העלה את התיקייה cowork/ ל-Cowork plugins
  2. אשר את ה-manifest ב-Cowork UI
  3. הפעל את הסוכנים מתוך ה-plugins panel
  4. זרימה זהה ל-Claude Code
repos/plugins/point-to-power/cowork/
ידני

Claude.ai Projects

בלי תלות בפלאגין. שני Projects נפרדים ב-Claude.ai, עם system prompt + knowledge files.

  1. צור Project ב-Claude.ai בשם Point, הדבק את ה-system prompt
  2. העלה את 20 קבצי ה-knowledge של Point
  3. חזור על אותו דבר ב-Project שני בשם POWER (17 קבצים)
  4. העברת handoff: copy-paste ידני בין שני ה-Projects
repos/projects/point-to-power/
!

הערות פלטפורמה. ל-target PowerPoint נדרש Copilot Pro או Teams license (תוסף Claude-in-PowerPoint). ל-target HTML נדרש Claude.ai רגיל, לא Claude Code. תוכן בעברית עם NotebookLM Audio Overview: יוצמדו אזהרות RTL audio quality.
